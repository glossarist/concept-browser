<h2>Glossarist Vocabulary Browser</h2><p>The Glossarist Vocabulary Browser is a web application for browsing, searching, and exploring terminology datasets managed using the <a href="https://github.com/glossarist">Glossarist</a> concept model.</p><h2>Glossarist Concept Model</h2><p>Glossarist implements a terminology management model that builds on and extends multiple ISO standards:</p><ul><li><strong>ISO 10241-1</strong> — terminology entries (designations, definitions, notes, examples, sources)</li><li><strong>ISO 30042 (TBX)</strong> — terminology data exchange format</li><li><strong>ISO 12620</strong> — data category registry (term types, relationship types)</li><li><strong>ISO 25964 / SKOS</strong> — thesaurus interoperability (broader/narrower, exact/close matches)</li><li><strong>ISO 639 / ISO 15924 / ISO 24229</strong> — language, script, and transliteration system identifiers</li></ul><p>The model provides structured management of concept definitions, designations (terms, symbols, abbreviations), multi-language localization, and semantic relationships between concepts.</p><h2>Ontology</h2><p>The <a href="/ontology">Glossarist OWL ontology</a> defines the RDF/OWL classes and properties used to describe terminology data. It models concepts with multilingual localizations and typed designations using the SKOS-XL pattern, aligned with SKOS, ISO 25964, PROV-O, and Dublin Core Terms.</p><p>The ontology includes 20 classes, 42 object properties, 48 datatype properties, and 10 SKOS taxonomy schemes for controlled vocabularies.</p><h2>Data Formats</h2><p>Each dataset is available in multiple serialization formats including JSON-LD, Turtle (TTL), TBX (ISO 30042), and YAML.</p><h2>Open Source</h2><p>Glossarist is open source software. Visit the <a href="https://github.com/glossarist">GitHub organization</a> for source code and documentation.</p>
